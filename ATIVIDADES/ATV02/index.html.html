Este guia apresenta alguns conceitos, áreas e comandos importantes para quem está começando a estudar programação.

Etapas para Aprender Programação

  1. Aprender lógica de programação
  2. Conhecer uma linguagem
  3. Criar pequenos programas
  4. Estudar banco de dados
  5. Desenvolver projetos

Conceitos Importantes

Algoritmo
Conjunto de passos utilizados para resolver um problema.
Variável
Espaço utilizado para armazenar um valor.
Programa
Conjunto de instruções executadas pelo computador.
Banco de dados
Sistema utilizado para armazenar e organizar informações.
Código-fonte
Conjunto de instruções escritas pelo programador.
